# Aircraft Engine Crankshaft Design and Analysis

## Project Overview

This academic project examines crankshaft design considerations for a
Rotax 503UL DCDI aircraft engine. The report discusses crankshaft
components, design parameters, preliminary torsional stress calculations,
and vibration calculations using Python.

## Project Topics

- Crankshaft components and design criteria
- Material and geometric design considerations
- Preliminary torsional stress calculations
- Natural frequency calculations using Python
- Assumptions and limitations of the analysis

## Project Report

[Open the project report](Crankshaft_Project_Report.pdf)

## Tools

- Python and NumPy for the calculation examples shown in the report
- Engineering calculations for preliminary design analysis

## Limitations

The report uses simplifying assumptions. For example, its torsional
stress calculation does not include bending stress or all real operating
conditions. The results should not be treated as a validated aircraft
engine design.
